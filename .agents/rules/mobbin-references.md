# Mobbin Reference Guidelines

When the user mentions Mobbin or requests designs inspired by Mobbin:
1. Check `mobbin_refs/` in the workspace for any uploaded screenshots or UI inspiration files.
2. If the user provides a Mobbin URL (e.g., `mobbin.com/...`), use `browser_subagent` or `read_url_content` to review the visual structure, layout patterns, and design details.
3. If the user copied a screen from Mobbin into Figma or Paper ("Copy to Figma"), use the respective MCP tools to inspect the exact vector layers and JSX.
4. Translate Mobbin design patterns into modern, clean, production-ready HTML/CSS with smooth interactions, high visual polish, and responsive layouts.
